# Context Atlas (임시 이름)

글로벌 언어·문화 맥락 사전과 자기점검 테스트 웹앱. 표현의 의미·맥락·배경을 판정 대신 맥락과 함께 기록한다.
같은 저장소의 「외계어 악보」와는 별개 프로젝트이며 이 폴더만으로 동작한다. 외부 의존성과 빌드 과정이 없다(Node 20 이상).

## 실행

```bash
cd context-atlas
```

```bash
npm run create-admin -- <관리자별명> <비밀번호 10자 이상>
```

```bash
npm start
```

`http://localhost:8090` 에서 열린다. 환경 변수: `PORT`, `ATLAS_DATA_DIR`(기본 `./data`), `ATLAS_ADMIN_HANDLE`·`ATLAS_ADMIN_PASSWORD`(시작할 때 관리자 생성), `ATLAS_SECURE_COOKIE=1`(HTTPS 배포), `ATLAS_TRUST_PROXY=1`(프록시 뒤에서 IP별 속도 제한).

```bash
npm test
```

사이트명·도메인 표시·연락 창구는 관리자 화면 → 설정·데이터에서 바꾼다. 실제 도메인 연결은 호스팅에서 한다.

## 구조

| 경로 | 역할 |
| --- | --- |
| `server/seed-entries.js`, `seed-sources.js` | 초기 편집 자료 50건과 출처 23건. **서버에서만 읽는다**(비공개 초안 포함) |
| `server/model.js` | 허용 값, 공개 뷰, 검색·필터, 통계, 공개 차단 규칙(순수 함수) |
| `server/app.js` | HTTP API, 세션, 권한 검사, 속도 제한, 정적 파일, 보안 헤더 |
| `server/store.js` | JSON 파일 저장(`data/atlas-db.json`), 데이터 버전 |
| `public/` | 프런트엔드(바닐라 ES 모듈). 디자인 값은 `styles.css` 맨 위 CSS 변수 |
| `public/js/i18n.js` | 화면 문자열 5개 언어(en 기본, ko, ja, zh-Hans, es) |
| `tests/api.test.js` | 실제 HTTP로 검증하는 테스트 |

## 지켜지는 규칙 (코드로 강제)

- 초기 50건 중 ‘추가 조사’ 11건(W13–W20, N02–N04)은 비공개 초안이다. 공개 API·통계·검색·관련 표현·프런트엔드 번들 어디에도 나오지 않는다.
- 공개 상태는 관리자만 바꾼다. `source_check_status: needs_research` 이거나 권리 상태가 불명확한 항목은 관리자도 그 상태를 먼저 해소해야 공개할 수 있다(가져오기 때도 초안으로 강등).
- 분류는 단어가 아니라 용법(`usages[].classification`)에 붙는다. 출처 확인·편집 검토·현지 화자 검토·번역·권리는 서로 다른 필드다.
- 화면 언어와 표현 원어는 독립적이다. 번역이 없으면 원문 + ‘번역 검토 중’을 보여 주고 지어내지 않는다. 영어 본문은 검수 전 초벌 번역으로 표시된다.
- 경험 기록은 비공개 초안이 기본이고, 공개는 별도 동의 + 운영자 승인 후다. 동의 전 초안은 관리자 API로도 나가지 않는다. 통계는 공개 승인된 고유 기록만 센다.
- 계정은 별명+비밀번호뿐이다(이메일·실명 미수집). 테스트 응답은 기기(localStorage)에만 저장한다.
- 댓글에는 추천 기능이 없고 분류에 영향을 주지 않는다. 신고는 운영자가 검토한다(자동 숨김 없음).
- 광고·제휴·유료 기능 없음. CSP `script-src 'self'` 로 외부 스크립트가 실행되지 않는다.
- 내보내기는 관리자 전용. 공개 일괄 다운로드 없음.

## 아직 하지 않은 것

- 정적 호스팅 전용 ‘로컬 데모’ 모드는 없다. 서버 없이 열면 연결 안내만 나온다.
- 비밀번호 재설정(이메일을 받지 않으므로 불가), 관리자 권한 부여 UI(스크립트로만), 댓글 수정 기능.
- 저장소는 단일 JSON 파일이다. 여러 서버 인스턴스·대규모 트래픽에는 DB 교체가 필요하다.
- 일본어·중국어·스페인어 **본문** 번역, 영어 번역 검수, 현지 화자 검토, 법률가의 권리·약관 검토는 이뤄지지 않았다. 안내 화면의 정책 문구는 초안이다.
- 관리자 항목 편집은 상태 선택 + JSON 편집 방식이다(필드별 전용 폼 아님).
